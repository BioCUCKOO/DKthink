# DKthink : CRE - TF - Gene Regulatory Inference AI thinking system

DKthink is an AI thinking system for reasoning **cis-regulatory element (CRE) - transcription factor (TF) - target gene** syntax.  Here, we introduce an API for using DKthink.

---

## Core Capability

Given a **CRE genomic coordinate**, **species**, **tissue**, and **DNA sequence**, DKthink:

Infers the CRE type;\
Identifies candidate transcription factors (TFs) binding the CRE;\
Reasons the most likely **target gene**;\
Assigns confidence of target gene and importance scores of biological function;\
Summarizes a s**tep-by-step rationale** suitable for reports.
